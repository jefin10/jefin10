## 🌟 Featured Projects

### EchoPay — Voice-Driven UPI Payment App &nbsp;&nbsp;[GitHub](https://github.com/jefin10/EchoPay) · [Live](https://echopay.jefin.xyz)
> Flutter · Django · Flask · Rasa · Keras · PostgreSQL

A hands-free UPI payment app powered by a 4-service microservices backend and a custom NLP pipeline.

- Built a **CNN-based intent classifier** with **90.44% accuracy** for voice command recognition
- Custom **NER pipeline** to extract payee, amount & phone number from raw speech transcriptions
- Fallback to **Rasa conversational AI** for ambiguous intents
- Secure auth via **OTP + biometric verification**

---

### Movieverse — Smart Movie Discovery App &nbsp;&nbsp;[GitHub](https://github.com/jefin10/MovieVerse) · [Live](https://movieverse.jefin.xyz)
> React Native · Django · Scikit-learn

A cross-platform movie app with a real hybrid recommendation engine — not just a list, an actual ML system.

- **Hybrid recommendation engine**: collaborative filtering (cosine similarity) + content-based on 5000+ movies
- **Naive Bayes NLP model** with 80% accuracy for mood-based recommendations from natural language input
- Swipe-based UI, watchlists, ratings, and **TMDB API** integration for real-time metadata & multilingual support

---

### RescueBytes — Disaster Response Platform &nbsp;&nbsp;[GitHub](https://github.com/jefin10/RescueBytes) · [Live](http://rescuebytes.jefin.xyz)
> React · React Native · Node.js · MongoDB · Docker · AWS

A full-stack crisis coordination platform — mobile app for victims/volunteers, admin dashboard for rescue teams.

- **Dynamic Safe Navigation Engine** using OSRM, cross-referencing weather data, danger zones & live hazards — **>75% route accuracy**
- Integrated **Gemini AI** for real-time in-app emergency guidance
- One-tap **SOS with automatic GPS capture**
- Deployed on **AWS** with Docker Compose (3-container architecture)
